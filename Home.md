## Cómo Usar Este Cerebro con Claude Code

Desde **cualquier proyecto**, puedes consultar info de otros proyectos vía CLI:

```powershell
# Buscar en el cerebro
obsidian search query="PTM Novo" vault=Obsidian

# Leer una nota específica
obsidian read file="PTM Novo" vault=Obsidian

# Buscar por tag
obsidian tags vault=Obsidian
```
